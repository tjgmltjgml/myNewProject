About

Practice & tools

This site gathers eleven semester projects built with creative computation in mind. Each piece explores a different corner of p5.js — from procedural landscapes and particle motion to audio analysis, cellular automata, typography, and WebGL.

Work is static and self-contained so you can open any sketch in the browser with no install. Replace placeholder GitHub links with your own repository paths when you publish.
